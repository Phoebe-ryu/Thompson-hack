# tompthon

ケン・トンプソンの "Reflections on Trusting Trust" を意識した、コンパイラバックドア／クワインの実験用リポジトリです。学習，検証目的のコードです。

## ファイル

| ファイル | 内容 |
| --- | --- |
| `cc.c` | ソースを `gcc` に流し込むラッパー。`login.c` をコンパイルする際にバックドアを注入し、自分自身 (`cc.c`) をコンパイルするとクワインを出力する |
| `cc.s` | 上記のアセンブリ版。バックドア用の認証情報が異なる (`hoge` / `0987`) |
| `login.c` | ユーザー名・パスワードを比較する簡易ログイン |
| `quine.c` | 自分自身のソースを出力する簡易クワイン |

## 使い方

```sh
gcc cc.c -o cc

# 通常のコンパイル
./cc login.c -o login

# バックドア入りの login が生成される
./login   # user: hoge / pass: 0987 で成功

# 自分自身を再生成 (クワイン)
./cc cc.c
```

バックドア用の認証情報は `cc.c` の `backdoor_usrname` / `backdoor_pass` で変更できます。
